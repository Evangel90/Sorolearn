Sorolearn

Small exercises to get you used to building on Stellar and writing Soroban smart contracts.

Every exercise is a tiny piece of broken code with tests. Fix it, save, and Sorolearn tells you instantly whether you got it. Start with the network itself, then write, test and review contracts.

Get started Open in Codespaces

AI can write your Soroban contract. Sorolearn teaches you to tell when it's wrong.

Stellar first

Accounts, keys and StrKeys, reserves, multisig, transactions, network-specific signatures and classic assets, built with the real Stellar types and checked against the Stellar CLI.

Soroban by fixing it

Contract functions, types, storage and TTL, errors, auth, events, tokens, cross-contract calls and ledger time. Each exercise compiles against soroban-sdk 29.

Review the AI

A security track of plausible, AI-style contracts with one planted vulnerability each. The happy path passes; an exploit test proves the attack. Fix the contract.

Graduate on-chain

sorolearn graduate deploys your contract to testnet, where a registry contract examines it with cross-contract calls and records you. See the graduates.

Offline or in the browser

Run it locally (fully offline after a one-time setup) or open it in GitHub Codespaces with Rust, the Stellar CLI and a pre-built SDK ready to go.

Watch mode & hints

Sorolearn re-runs the tests every time you save. Stuck? Type h for a hint, read the topic README, then compare with the reference solution once you pass.

Quick start

git clone https://github.com/Evangel90/Sorolearn.git sorolearn
cd sorolearn
cargo install --path .
sorolearn setup   # once: downloads and pre-builds the SDK
sorolearn         # start watch mode

Need Rust? See Setup. Want to skip installing anything? Open it in GitHub Codespaces.
