Why Sorolearn

You won't write every line by hand.
You still need to know when it's wrong.

AI writes the first draft now

Ask for a token, a vault or a vote and you get a contract that compiles, looks right and passes the obvious tests, in seconds.

It fails where it costs money

A require_auth on the wrong address. A negative amount. Storage that quietly expires. Bugs like these only get caught by someone who understands the platform.

Fixing code builds that understanding

Every exercise is broken on purpose. Repairing it teaches the same skill as reviewing AI output: reading a contract and knowing exactly why it fails.

The course

From first contract to testnet in four movements.

Every exercise is a small, broken program with tests. Save the file and Sorolearn re-runs them instantly, so you always know what's wrong and exactly when it's fixed.

An exam graded by a smart contract

sorolearn graduate uploads your contract to Stellar testnet. A registry contract deploys a fresh copy, examines it with cross-contract calls, and only then records you and emits a Graduated event. No one self-reports; anyone can verify. See the graduates →

$ sorolearn graduate [5/6] Upload the contract code to testnet [6/6] Ask the registry to examine your contract and record you ✓ You are Sorolearn graduate #2!
