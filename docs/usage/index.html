Usage

Read, fix, save, repeat. Sorolearn takes care of compiling and testing.

Watch mode

sorolearn

Sorolearn shows the current exercise, for example exercises/04_storage/storage1.rs. Open it in your editor, read the comments, and make the code compile and the tests pass. Every time you save, Sorolearn re-runs the tests. When the exercise passes, type n + Enter for the next one.

KeyAction
nnext exercise (once the current one passes)
hshow a hint
llist all exercises and your progress
rre-run the current exercise
qquit (progress is saved)

Rules of the game

  • Don't edit the tests at the bottom of each file. They are the spec.
  • Each topic folder has a README.md with the background you need.
  • Reference solutions live in solutions/. Compare once you've passed, not before.

Kinds of exercises

Soroban contracts

Small #![no_std] contracts tested against Soroban's simulated environment: no network needed.

Stellar lessons

Plain Rust against the real Stellar types: derive keys and addresses, apply reserve and multisig rules, build, hash and sign transactions, parse assets. Expected values (like a transaction hash) were checked against the Stellar CLI.

Security: review the AI

Each contract looks fine and its happy_path tests pass. An exploit_ test reproduces a real attack. Fix the contract so the attack fails.

sorolearn graduate [identity]deploy your quiz1 poll to testnet and take the on-chain exam

Graduating

When you finish, run sorolearn graduate. It creates a funded testnet account, builds your quiz1 poll to WebAssembly, uploads it, and calls the Sorolearn registry contract. The registry deploys a fresh copy, examines it with cross-contract calls, and records you as a graduate. Every Stellar CLI command is printed as it runs. Your record appears on the graduates page.

Contributing exercises

  1. Write the solution in solutions/<topic>/<name>.rs.
  2. Copy it to exercises/<topic>/<name>.rs and break it in an instructive way.
  3. Add an entry with a hint to info.toml.
  4. Run sorolearn dev check: every solution must pass and every exercise must fail.
