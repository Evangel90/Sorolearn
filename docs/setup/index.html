Setup

Run it anywhere.

Two ways to run Sorolearn: in your browser with nothing to install, or locally, where it works fully offline after a one-time setup.

In the browser (GitHub Codespaces)

Click the button, wait for the codespace to open, then type sorolearn in the terminal. Rust, the sorolearn command, the Stellar CLI and a pre-compiled Soroban SDK are already installed.

Open in Codespaces

A free GitHub account includes a monthly Codespaces allowance; Sorolearn's repo is public, so it runs on yours.

Locally

1. Install Rust

You need Rust 1.91 or newer. Install it with rustup, or update an existing install:

rustup update stable

2. Get Sorolearn

git clone https://github.com/Evangel90/Sorolearn.git sorolearn
cd sorolearn
cargo install --path .

This installs the sorolearn command. Run it from inside the sorolearn folder. (cargo run --release works too, without installing.)

3. One-time setup

sorolearn setup

Downloads and pre-compiles the Soroban SDK (a minute or two). It runs automatically the first time if you skip it. Afterwards every build uses cargo --offline against a pinned lockfile, so Sorolearn works on a plane or behind a firewall.

4. Start

sorolearn

Then open the exercise it shows in your editor. See Usage.

Editor

Any editor works. In VS Code, install rust-analyzer: the repo's settings link the generated exercise workspace, so you get completions and inline errors inside exercise files. The repo also ships a Dev Container, so VS Code with Docker gives you the same environment as Codespaces.

Optional: the Stellar CLI

Only needed for the final topic: the testnet lab and sorolearn graduate. It's pre-installed in Codespaces.

On macOS:

brew install stellar-cli

Anywhere else:

cargo install --locked stellar-cli

Then add the WebAssembly target:

rustup target add wasm32v1-none

Troubleshooting

  • "soroban-sdk needs Rust 1.91 or newer": run rustup update stable.
  • "Could not find info.toml": run sorolearn from the repository folder.
  • Build cache deleted? Sorolearn notices and re-runs setup (this one needs internet).
